# Senior Software Engineer, Realtime Systems

Northstar Robotics is hiring a Senior Software Engineer to build low-latency collaboration and control systems for remote robotics operations.

Responsibilities:
- Build TypeScript and Node.js services for realtime session orchestration.
- Design WebRTC and WebSocket media/control paths with predictable latency.
- Improve observability for streaming sessions, device events, and operator workflows.
- Collaborate with robotics, product, and infrastructure teams.

Required experience:
- 5+ years backend or full-stack engineering.
- Production TypeScript or JavaScript.
- Realtime systems using WebRTC, WebSockets, or similar streaming protocols.
- Distributed-system debugging, metrics, tracing, and incident response.
- Clear communication across engineering and product teams.
